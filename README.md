# PEPITAS

**Criadores:** Fábio Leyser Gonçalves | Matheus Garcia Grael

Pepitas é um ambiente virtual que simula tarefas operantes para seres humanos. Nesse ambiente, o sujeito tem que emitir uma resposta operante previamente determinada (e.g., clicar com o botão direito) em uma área específica da tela. O projeto tem como objetivo oferecer um ambiente de testes operantes flexível para pesquisadores e estudantes de análise do comportamento.

## 🚀 Funcionalidades

- Suporte para rotinas experimentais personalizadas
- Programação prévia para diversos esquemas de reforço 
- Geração automática de registro
- Suporte para esquemas concorrentes

## 📋 Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina as seguintes ferramentas:
- [Python 3.14](https://www.python.org/downloads/)
- [Git](https://git-scm.com)
- [pygame-ce 2.5.8](https://pypi.org/project/pygame-ce/) (será instalado no próximo passo)

## 🔧 Como instalar e configurar

Siga os passos abaixo para rodar o projeto localmente:

1. Clone este repositório:
```bash
git clone https://github.com/M-Grael/pepitas.git
```

2. Acesse a pasta do projeto
cd pepitas

3. Instale as dependências:
[ATENÇÃO] A biblioteca correta é o Pygame Community Edition (pygame-ce). O comando abaixo já instalará a versão correta listada no projeto para evitar conflitos com o pygame comum:
```bash
pip install -r requirements.txt
```
=====================
   COMO USAR
=====================
no terminal, execute:
```bash
python main.py
```
